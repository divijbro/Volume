# Interactive 3D Volume Simulator

An interactive 3D volume simulator built with React, Vite, TypeScript, and React Three Fiber. Explore cubes, cuboids, and cylinders; build cuboids layer by layer with unit cubes; check your understanding with generated challenges; and record a simple dimension experiment.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run:

```bash
npm run build
```

No backend, account, or API key is required.
